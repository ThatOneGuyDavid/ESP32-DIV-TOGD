# CC1101 module details

The sub-GHz radio is the DWEII CC1101 module with SMA antenna. The photographed
board has an eight-position header but no readable
silkscreened pin names. The table is therefore a provisional reference for
the common CC1101 SPI breakout layout, not a confirmed wiring map.

> **CC1101 module reference** — 433 MHz module with SMA antenna.
>
> ![CC1101 module](images/cc1101/cc1101-module.jpg)

Product reference: [DWEII CC1101 module listing](https://www.amazon.com/dp/B0CSYX1454)

## Provisional SPI/header reference

| Signal | Typical CC1101 breakout role | Status |
|---|---|---|
| VCC | 3.3 V supply | Verify on this board |
| GND | Ground | Verify on this board |
| SCK | SPI clock | Verify on this board |
| MOSI / SI | SPI data to module | Verify on this board |
| MISO / SO | SPI data from module | Verify on this board |
| CSN / CS | SPI chip select | Verify on this board |
| GDO0 | Configurable interrupt/data output | Verify on this board |
| GDO2 | Configurable interrupt/data output | Verify on this board |

Do not connect this module from the table alone. Confirm header order with a
continuity test or a board-specific diagram before applying power.
